# suti-view-2026 redirect stub

`index.html` here is the whole content of the `vvorski/suti-view-2026` GitHub
repository — the name freed when that repo was renamed to `kiyo-plays`
(`docs/todo.md` entry 142 in `kiyo-plays`).

It exists only so that `https://vvorski.github.io/suti-view-2026/` keeps
answering: a GitHub Pages project site is not covered by GitHub's own
post-rename redirect, so without this stub the old URL would 404 forever.

## To (re)deploy this stub

1. `vvorski/suti-view-2026` on GitHub, public, containing this `index.html` on
   its default branch, nothing else.
2. GitHub Pages enabled on that repo, serving the default branch root — no
   build step, this is static.

The redirect preserves the visitor's query string and hash — a link like
`?geometric=shards&mix=screen` lands on the same view at the new address,
not on the defaults.
